# Личный перенос архива

Открытый репозиторий для переноса файла между компьютерами. Вход в GitHub для скачивания не требуется.

## Как скачать и собрать архив на Windows

1. Откройте [страницу загрузки](https://github.com/goldFRAGG/private-transfer-2026-10-08/releases/tag/transfer-v1).
2. Скачайте все двенадцать файлов `archive.rar.part*` в одну папку.
3. С той же страницы скачайте `manifest-v2.json`, `assemble-v2.ps1` и `assemble-v2.cmd` в эту папку.
4. Дважды нажмите `assemble-v2.cmd`. Он проверит части и соберёт исходный RAR.

Оставьте около 16 ГБ свободного места для частей и восстановленного архива. После сообщения `Ready` откройте полученный RAR в WinRAR или 7-Zip.

Части — последовательные фрагменты исходного файла; отдельно распаковать их нельзя. Сборка проверяет SHA-256 каждой части и полного архива. Если файл с именем исходного архива уже существует, сборка остановится без перезаписи.
